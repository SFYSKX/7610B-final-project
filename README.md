# Ledger Market

> **本包供每位接收者独立部署。** 本地测试运行 `npm run demo`；使用 Sepolia 前必须创建自己的 Safe 并部署合约。首次解压后只连接 MetaMask 不会自动获得平台配置。请先阅读 [每人独立部署指南](docs/INDEPENDENT_DEPLOYMENT.md)。

Ledger Market 是一个用于教学与测试网实验的 NFT 交易与风险准备金 DApp。持有人可以把 NFT 按固定价格出售或发起公开拍卖，买家用链上的 ETH 买入或竞价；平台收取成交手续费，将其中一部分分配到风险准备金。发生模拟损失时，管理员共同登记预算与赔付资格，用户提交申请，经审核后领取赔付款。

这个项目用于观察和调试一条完整业务链：**资产授权 → 合约托管 → 买卖或竞拍 → 资金领取 → 费用分配 → 多人审批与赔付**。它适合课程演示、合约和前端联调、多账户权限测试，也适合研究业务如何由链上合约执行。接收者可以建立自己的独立平台，使用自己的用户和管理员账户测试。

## 实现了哪些功能

| 功能 | 使用者能完成的操作 |
|---|---|
| 我的资产 | 查看已配置集合中的 NFT，区分集合地址与 Token ID，分别授权交易市场或拍卖市场 |
| 定价交易 | 卖家托管挂牌、调价、撤单；买家购买；卖家领取净卖款 |
| 公开拍卖 | 设置底价、最小加价和结束时间，多人竞价，被超价者领取退款，到期结算后分别领取 NFT 与卖款 |
| 自动结算 | 专用服务用已授权账户检查到期拍卖并发交易；运行服务和支付 Gas 是部署方的责任 |
| 资产溯源与交易记录 | 查询转移与成交事件、导出溯源 CSV，查看本浏览器记录的操作及交易状态 |
| 手续费分配 | 默认收取成交额的 1%，归集后按 50% / 50% 分配到准备金和管理金库 |
| 风险准备金与我的赔付 | 注资、预留事故预算、登记受益人资格、用户申请、多签审核、领取赔款、释放未批准预算 |
| 共同管理 | 多人批准集合许可、单件 NFT 禁用、费率、暂停和结算账户等管理操作；普通账户不显示管理页面 |

## 谁使用这个系统

卖家、买家和竞价者通过同一个 DApp 操作，角色取决于当前持仓与交易，同一账户可以在不同交易中承担不同角色。管理员共同控制平台规则和赔付审批；专用 Keeper 账户仅承担授权范围内的自动结算。部署者负责首次安装、部署与测试资产发行，不会仅因部署了合约而自动获得 Safe 的管理权限。

本地实验提供测试账户和 LocalCouncil 多签，便于一人在浏览器切换角色。Sepolia 使用接收者自己的 MetaMask 账户与 Safe 多签；普通交易在 DApp 内完成，需要多签的管理操作由 DApp 生成交易 JSON，再到 Safe 批准和执行。

## 部署前先了解什么

请先读 [项目介绍与业务流程](docs/PROJECT_OVERVIEW.md)，了解页面、角色、资产和资金如何流动，再按下面的安装步骤运行。它也说明了项目尚未提供的能力：准备金需要人工审核，不会自动认定或补偿损失；合约不会自行定时执行，自动结算依赖在线服务；页面记录不等于完整的公链索引。

技术上，项目由 React 网页、Solidity 合约、Node.js 结算服务和部署测试脚本组成，使用 Hardhat、Vite 与 ethers；没有数据库或传统业务后端。网页通过钱包和 RPC 与链交互，资金与权限规则由合约执行。

本包用于在接收者自己的电脑上安装、运行和部署。没有预装依赖、私钥、个人账户、现成部署地址或运行数据。首次启动必须创建自己的本地部署；使用 Sepolia 时必须配置自己的账户和 Safe，并部署自己的业务合约。

## 了解项目后开始运行

1. 安装 Node.js 22.x（npm 随 Node 安装），解压压缩包。
2. 在包含 `package.json` 的目录打开终端。以下命令均在该目录运行。
3. 执行：

```text
node --version
npm --version
npm ci
npm run demo
```

Node 版本应为 `v22.x`。首次安装需要联网下载依赖。一键演示需要本机 8545 和 5173 端口空闲；终端输出网页地址后，打开通常为 http://127.0.0.1:5173 的地址，点击 **本地演示**。默认连接本地卖家，可用账户下拉框切换角色。保持终端运行，Ctrl+C 停止演示。

本地演示自动编译、启动内存链、部署合约、创建测试资产、配置权限并启动自动结算服务。无需 MetaMask、RPC 服务商或 `.env`。所有本地账户均为节点提供的公开测试账户，只用于本地链。

## 运行命令

| 命令 | 作用 |
|---|---|
| `npm ci` | 按锁文件安装依赖 |
| `npm run demo` | 本地完整演示：RPC 8545、网页 5173 |
| `npm run demo -- --isolated` | 本地完整演示：RPC 18545、网页 15173 |
| `npm run compile` | 编译合约并导出 ABI，不部署或铸造 |
| `npm test` | 架构、合约、客户端和部署工具测试 |
| `npm run build` | 生成前端生产构建 |
| `npm run dev` | 只启动前端，必须已有对应链的部署清单 |
| `npm run deploy:sepolia` | 使用自己的配置部署 Sepolia 业务合约 |
| `npm run deploy:test-assets:sepolia` | 部署可恢复的测试 NFT 集合 |
| `npm run mint:sepolia` | 按指定接收地址铸造；每次运行都新增资产 |
| `npm run validate:sepolia` | 只读验证自己的 Sepolia 部署和初始化配置 |
| `npm run settle:sepolia` | 使用自己的专用账户持续执行到期结算 |

`demo:v2` 是备用端口演示命令的兼容别名。`demo-v1` 是测试集合部署请求的默认标识。这两个字符串是脚本标识，不是个人环境或外部账户。

## 项目边界

业务合约的管理员在部署时固定为管理合约；前端隐藏页面不能替代链上授权。普通用户可以使用自己的钱包交易，但不会因此成为管理员。需要自己的管理员权限时，应在自己的 Safe 下新建部署。

本地内存链在停止后不保存链状态。Sepolia 合约和交易会保留，停止网页或后台服务不会撤销交易。合约不可代理升级；修改规则需要新部署，并保留已有资产退出方式。

项目使用有限的查询窗口和浏览器操作日志，没有数据库或完整公链索引服务。自动结算需要专用服务在线且账户有 Gas。风险准备金依赖人工审核和有限预算，不承诺覆盖所有损失。软件用于教学与测试网，测试通过不等于安全审计。
