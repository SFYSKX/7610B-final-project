# 账户、网络与权限

## 本地独立实验

Hardhat 节点创建一组公开测试账户，提供虚拟 ETH。页面“本地演示”通过节点的解锁账户签名；它不使用个人 MetaMask 私钥。每台电脑上的本地链状态独立，即使默认测试地址相同，也不是共享账户资产或公共链部署。

| 零基索引 | 页面角色与用途 | 初始 NFT |
|---|---|---|
| 0、1、2 | 三名 LocalCouncil 管理签名者；索引 0 也是部署者和 NFT 发行者 | 无 |
| 3 | 卖家 | 1、4 |
| 4 | 买家 | 2、5 |
| 5 | 第二竞价者 | 3、6 |
| 6、7、8 | 备用普通账户 | 无 |
| 9 | 专用自动结算账户 | 无 |

这里的编号是本地节点账户索引，不是接收者钱包中的账户名称。初始编号适用于全新 demo 链，已有链应以实际输出和持仓为准。

需要一套不同地址的本地测试账户时，可在自己的 Hardhat 节点配置中使用自己生成的本地专用助记词，并保持上述角色索引分配，然后部署到全新节点。部署、初始化和测试脚本按节点返回的账户索引取地址，不依赖作者的钱包。助记词只保存在本机私有配置中，不使用有真实资产的钱包助记词，不写入共享源码。任意指定已有钱包作为本地管理员则需要调整下述配置。

要用 MetaMask 调试本地交互，可以手动添加 chain ID 31337 和实际本机 RPC，并使用该本地节点的公开测试账户。另建普通钱包也可以接收本地测试 ETH 和 NFT，然后作为普通用户交易。更换本地管理员需要重新部署 LocalCouncil，并同步调整依赖固定 signer 索引的部署、seed、smoke 和 keeper 配置；仅更改前端显示或钱包名称不会授予权限。需要自主选择管理钱包的标准部署流程见下文 Sepolia。

## 使用自己的 Sepolia 账户

建议准备以下角色，每个需要发交易的钱包都应有 SepoliaETH。角色名只是文档标签，地址全部由接收者自行决定。

| 角色标签 | 用途 | 配置方式 |
|---|---|---|
| DEPLOYER | 部署业务合约、发行测试 NFT；可以兼任 ADMIN_1 | 私钥仅写本机 `SEPOLIA_PRIVATE_KEY` |
| ADMIN_1、ADMIN_2、ADMIN_3 | 审查并批准管理交易 | 在自己的 Sepolia Safe 中配置三名 owner，门槛 2/3 |
| SELLER | 持有、授权、挂牌 NFT | 作为铸造接收者，操作时连接自己的钱包 |
| BUYER_1、BUYER_2 | 买入、竞价、申请/领取赔付 | 各自在 MetaMask 中签名 |
| KEEPER | 到期结算专用账户 | 私钥写本机 `SETTLER_PRIVATE_KEY`，公开地址经 Safe 授权 |

使用 DEPLOYER 兼任 ADMIN_1 时，共七个不同普通账户。Keeper 不需要是 Safe owner。Safe 是另一个管理合约地址，没有一把需要导出的“Safe 私钥”。不要把普通账户地址填成 Safe 地址。

包中所有账户配置为空，所有部署清单都由接收者运行脚本生成。拥有一份源码或知道合约地址，不会获得别人部署的管理权。创建自己的 Safe 并部署自己的合约，才可以由自己的管理员进行调试。

## 权限表

| 行为 | 谁可以执行 |
|---|---|
| NFT 授权 | 当前 NFT 持有人 |
| 调价、撤销定价订单 | 对应卖家 |
| 买入、竞价 | 满足业务条件的普通账户 |
| 卖款、退款、NFT、赔付领取 | 该项链上权益的所有人 |
| 费用归集、固定方向分账、显式准备金注资、审核期后的事故关闭 | 当前管理签名者或管理合约 |
| 集合许可、单件禁用、费率、暂停、结算账户、事故预算、申诉批准/拒绝 | LocalCouncil 或 Safe 达到门槛后执行 |
| 到期拍卖结算 | 被授权的 Keeper，或管理合约应急执行 |

Sepolia 上 A/B/C 等普通签名者不能直接调用要求 `onlyOwner` 的管理方法，必须让 Safe 成为实际调用方。固定方向维护使用 `onlyAdministrator`，允许 Safe 的当前 owner 直接发交易。

普通用户菜单隐藏“风险准备金”和“共同管理”；自主提交申诉和领取赔付在“我的申诉”；NFT owner 另有“铸造管理”入口。交易记录按当前账户过滤，管理员可查看本浏览器内当前部署的账户记录。公链本身的交易仍公开。

## 调试时的隔离

每次换账户先核对页面账户行，待交易确认后再切换。每次换网络核对 chain ID、部署清单和目标合约。只在 `.env` 中配置自己的测试部署/结算密钥；其他用户与管理员在钱包中签名。私钥在以太坊各 EVM 网络上控制同一地址，不能将切换网络当成密钥隔离。
