# 管理员批量操作与 Gas 优化

本分支为 Marketplace 和 AuctionHouse 添加两个管理接口，并在管理页面添加四个对应入口：

- `setTokensBlocked(collection, tokenIds, blocked)`：一次禁用或恢复同一集合中的多个 NFT。
- `setCollections(collections, allowed)`：一次配置多个集合；合约支持每个集合独立的布尔值，页面提供统一启用或停用。

每批 1–100 项；所有设置仍要求合约 owner（多签）调用。任何一项无效则整笔交易回滚。集合启用仍校验 ERC721 接口，逐项发出原有事件，单项接口保持兼容。页面拒绝重复输入；直接调用合约时重复项按顺序处理，最后一次值生效。

## 使用

部署本分支的新合约并更新部署清单后，进入管理员页面，选择批量操作。列表支持英文逗号、中文逗号和空白分隔。生成预览后，本地使用一份 LocalCouncil 提案；Sepolia 下载 Safe 交易 JSON，经原有签名门槛执行。执行前仍进行模拟，最终结果以执行时链上状态为准。

旧部署没有新接口，不能仅通过更新前端启用。不要覆盖仍有资产或负债的旧部署清单；请使用独立测试部署验证，并另行制定正式迁移方案。本次没有部署或发送链上交易。

## Gas 对比

Solidity 0.8.24，optimizer 200 runs，Paris EVM，本地 Hardhat/LocalCouncil。比较同一初始快照下，10 个从未禁用的 Token ID：

| 方案 | 提案/批准/执行交易总数 | 总 gas |
| --- | ---: | ---: |
| 10 次单项操作 | 30 | 3,722,928 |
| 1 次批量操作 | 3 | 861,617 |

此场景总 gas 减少约 **76.85%**。包含提案 calldata 存储、批准和执行成本；不是 Safe 实网估算，也不是 ETH 费用承诺。实际成本取决于批次数量、初始存储状态、多签实现及网络费用。
