# 交易凭证导出与搜索排序

## 交易凭证

在交易市场选择“全部近期订单”，已成交订单卡片提供“凭证格式”和“导出交易凭证”。公开拍卖中，有买家成交的已结算拍卖提供相同入口。较早记录可通过页面中的按 ID 查询导出，资产溯源中的成交事件也提供入口。

用户可选择 CSV 或 Excel `.xlsx`。CSV 使用 UTF-8 BOM，Excel 工作簿将地址、Token ID 和 ETH 金额保存为文本，保留大整数及 18 位小数精度。

导出内容包括 NFT 集合、Token ID、导出时读取的名称/描述/图片/属性/tokenURI、卖家、买家、实际 NFT 接收人、成交额、平台手续费、卖家净收入、交易哈希、区块及时间、成交交易 Gas 用量/费用/支付人，以及 NFT 交付状态。拍卖成交和领取 NFT 可属于不同交易，分别记录。

成交金额和平台手续费取自已确认的链上成交事件。导出会核对回执及区块哈希。Gas 费用属于整笔成交交易，可能由买家、Keeper 或多签执行账户支付。元数据来自导出时读取，文件会标明读取状态。元数据失败时仍可导出已验证的成交信息。

导出为只读操作，无需钱包签名或 Gas。每次扫描事件的区块范围有限，RPC 对区间有限制时会缩小请求。超过 60 秒会显示超时，支持重新尝试。切换账户、网络或离开组件会取消当前导出，防止旧会话触发下载。

## 搜索与筛选

交易市场和公开拍卖均支持以下组合条件。

- NFT 名称关键词，忽略大小写，支持中文。
- 精确 Token ID 和订单/拍卖 ID，Token ID 支持 0 和 uint256。
- 卖家地址，支持完整或部分地址，忽略大小写。
- 最低和最高 ETH 价格，支持 0 和 18 位小数，使用整数 wei 比较。

名称在用户开始输入时按最多四个并发请求读取。加载中会提示，失败会显示数量并提供重试。无名称或元数据读取失败的资产仍可按编号、卖家和价格查找。

筛选作用于当前载入的最近最多 40 条记录。交易市场原有“可购买 / 我的挂牌 / 已关注 / 全部近期订单”范围与新条件叠加。点击“重置搜索与排序”清空新增条件。

时间排序使用合约单调递增的创建编号，提供从新到旧和从旧到新。两市场均支持价格升降序。拍卖价格取最高出价，无出价时取底价。剩余时间排序以当前链上时间判断进行中的拍卖，已到期、已结算及已取消的项目置于末尾。

## 本地验收

使用 Node 22，运行 `npm ci`、`npm test`、`npm run build`。确认 18545/15173 端口空闲后运行 `npm run demo -- --isolated`。

1. 用两件不同名称、价格的 NFT 分别挂牌，检查名称、编号、卖家和价格区间可叠加，重置恢复列表。
2. 价格输入 0、18 位小数、最小值高于最大值、科学计数法，检查正确筛选或明确错误提示。
3. 创建不同底价、截止时间的拍卖，验证价格及剩余时间升降序，结束项目置于末尾。
4. 完成一次买卖及有出价拍卖，分别下载 CSV 和 Excel，用 Excel 打开核对地址、Token ID、金额、实际手续费和哈希。
5. 拍卖领取前导出应注明等待领取，领取到另一地址后导出应包含实际接收人及交付交易哈希。
6. 对未成交订单、取消拍卖和无人竞拍返还，确认没有成交凭证入口。
7. 查询旧订单/拍卖 ID 及资产溯源，检查历史成交入口。导出期间切换账户或离开页面，确认旧任务不会下载文件。
8. 元数据失败、RPC 超时、名称读取失败后重试，确认错误可见且原交易按钮继续可用。

本功能仅涉及前端和只读服务，可使用当前 main 对应的部署合约。

## 交易记录页的日志导出

“交易记录”页面的“导出日志”支持 CSV 和 Excel 格式选择，默认 CSV。每条日志占一行，包含记录时间、操作、状态、账户、网络、交易哈希、详细信息、管理地址和部署标识。导出范围与页面展示范围一致，普通账户只导出本人在当前网络和部署的记录，管理员可导出本浏览器该部署的其他账户记录。空列表时按钮禁用。切换账户、权限或离开页面会丢弃进行中的下载结果。

日志源于浏览器保存的操作记录。需要资产信息、成交额、手续费和链上回执时，在已成交订单、已成交拍卖或资产溯源的成交记录中使用“导出交易凭证”。
